在线游戏平台文档

管理后台概览

管理后台位于 game.zihua-chen.cn/admin/,供平台运营与开发商使用。账号由平台创建或经开发商自助注册,登录后按角色与权限控制可见页面与接口。开发商账号只能管理本开发商名下的游戏,越权返回 403。

页面一览

分组页面用途
概览仪表盘平台运行概览与待处理事项
内容生态开发商管理开发商资料、账号状态与旗下资源
内容生态分类管理大厅展示分类与游戏归属
内容生态游戏管理游戏信息、缩略图、联机参数与上下架状态
内容生态游戏版本按游戏提交版本:前端包与逻辑包上传或继承、申报 RTP 与抽成
内容生态游戏审核审查开发商提交的版本,通过即发布
运营中心内容运营大厅轮播、公告与推荐位维护
运营中心券管理金币券与补签卡的批次发放和启停
玩家与财务玩家管理玩家账户、余额、流水查询与处置
玩家与财务财务中心充值订单、渠道对账、发放批次、提现审核与风控工作台
玩家与财务管理员账号后台账号、角色授权、禁用与密码重置
数据与支持数据看板平台总览、转化漏斗、留存与游戏健康度
数据与支持客服工单玩家工单受理、回复、补偿与回合回放仲裁
系统管理菜单管理配置后台导航结构与入口排序
系统管理权限管理按菜单维护接口权限点
系统管理角色管理管理角色并分配权限
系统管理审计日志后台关键操作追踪

角色说明

  • 平台运营:可见全部页面。内容审核、玩家管理、财务、风控与系统管理属平台职能,开发商账号无权限。
  • 开发商:登录后仅可见与自身相关的页面,典型工作流是 游戏管理建游戏 → 游戏版本提包提审 → 版本迭代,详见开发商接入指南。
